Описание проекта:

Веб-сервер для планирования задач по расписанию c правилами повторения. Сервер хранит задачи в базе данных SQLite и предоставляет API для добавления, редактирования, удаления и отметки о выполнении задач.

Запуск локально:

Установите зависимости:
    ```
    go mod tidy
    ```

Задайте переменные окружения:
   ```
   set TODO_PORT=7540
   set TODO_DBFILE=scheduler.db
   set TODO_PASSWORD=12345
   ```
Запустите сервер:
   ``` 
   go run main.go
   ```

Откройте в браузере: http://localhost:7540/

Запуск тестов:

В файле tests/settings.go перед запуском настройте:

```
var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = true // поддержка правил w и m
var Search = true       // поддержка поиска
var Token = ""          // токен из /api/signin
```

Запустите сервер в отдельном терминале:
```
go run main.go
go test ./tests
```
